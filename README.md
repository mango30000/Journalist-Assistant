# Journalist-Assistant
## Тема Fullstack: Ассистент для журналистов: доска расследования, источники с уровнями доверия, карта связей, таймлайны событий, пакет доказательств для редактора.

## Назначение приложения: 
Система для журналистов, позволяющая структурировать данные: доска расследования, источники с уровнями доверия, карта связей, таймлайны событий, пакет доказательств для редактора

## Основные экраны
1.	Список расследований
2.	Доска расследуемого дела: источники, карта связей, хронология событий, пакет доказательств
3.	Карточка источника информации(сведения, уровень их доверия)
4.	Карта связей(визуализация связей между объектами расследования)
5.	Хронология событий 
6.	Пакет доказательств для редактора(ключевые документы, факты, выводы)

## Основные пользовательские сценарии
1.	Создание расследуемого дела
2.	Добавление источника информации
3.	Построение карты связей 
4.	Ведение хронологии событий
5.	Формирование итогового отчета с пакетом доказательств

## Инструкция запуска frontend
1. Склонируйте репозиторий:
git clone https://github.com/mango30000/Journalist-Assistant.git
2. Перейдите в папку frontend:
cd Journalist-Assistant/frontend
3. Установите зависимости:
npm install
4. Запустите приложение в режиме разработки:
npm run dev
5. Откройте в браузере адрес:
http://localhost:5173
